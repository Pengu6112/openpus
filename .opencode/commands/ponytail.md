If you have not loaded the `ponytail` skill this session, load it now with the skill tool.

Level requested: $ARGUMENTS

- Nothing, or `full`: apply the skill at its default level for the rest of this session.
- `lite` or `ultra`: apply the skill at that level for the rest of this session.
- `off`: stop applying the skill and go back to normal behaviour.

Confirm the active level in one line. Change no code.
